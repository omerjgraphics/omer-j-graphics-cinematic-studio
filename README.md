# OMER J GRAPHICS — Creative Studio Functional Core v0.3

Browser-based workspace. Open index.html or publish the repository root with GitHub Pages.

## Implemented
- Import raster images into the canvas preview.
- Change headline text and accent color.
- Export a 1920 × 1080 PNG composition.
- Save project state as JSON.
- Responsive interface; core features run in the browser.

## Not implemented yet
AI image generation and semantic image-to-prompt vision, OCR, PDF editing, PSD import/export, video/audio timeline playback and MP4/MOV rendering, advanced layer compositing, and offline AI models. These require separate engines/models or a backend. Do not treat their UI entries as functional.

## GitHub Pages
Settings → Pages → Deploy from a branch → main → /(root). Wait for the latest deployment to succeed in Actions.
